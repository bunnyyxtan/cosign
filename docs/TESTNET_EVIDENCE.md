## Notes on the failed checks

- **Junior shares and cover recorded**: the first `bold` run lost its receipt to an RPC null response, although the deposit had landed. A rerun deposited again, so cover was 20 MUSD instead of 10. The contracts were right; the script was not idempotent. Stages now skip steps whose effect is already on-chain.
- **Senior book / share value not reduced by the loss** (two entries): the check compared against a preview that included interest not yet booked. A direct Morpho liquidation nets that interest against the loss, so the figure fell by 0.000004 MUSD. The check now tests the enforced guarantee (last-synced principal) and reports the forgone interest.
- **Lender cannot double claim / Cosigner claim paid / Cosigner cannot double claim**: the first threshold ignored that rewards stream continuously; the resumed run saw more accrued stream. Exactness is established by the end-of-stream check: claims plus the vault remainder equal the distributed MEZO.
- The live `poke` stage did not record its last check (a repeat poke must not raise votes). veBTC power keeps decaying, so a later poke can legitimately lower votes again. Votes only ever go down on poke; that property is covered by the Foundry tests, not by this live run.

## Known limits shown by this run

- Direct Morpho liquidations bypass `CosignLiquidator`; unbooked interest can be netted against the loss.
- The 19x rule limits vault deposits, not Morpho borrowing. The borrower was able to borrow against the market while cover was thin.
- Cover is finite: a loss larger than cover falls on the senior lenders still in the vault.
- The oracle is a single-owner demo oracle. The price crash is a demonstration, not a market event.
